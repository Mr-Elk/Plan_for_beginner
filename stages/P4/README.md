# P4｜判断是否需要机器学习

这一阶段不是为了“给项目加模型”，而是学会用数据判断方案。可以尝试预测工单类型或优先级，但先用规则和简单统计建立基线。

## 从数据问题开始

先检查数据来源、字段、缺失、类别分布和标签可靠性。若“包含退款二字就标记退款”已经足够，就要把它作为对照，而不是直接训练复杂模型。

只有当问题和数据值得继续时，才划分训练、验证和测试集，选择代表性模型和指标。对分类任务，不要只看准确率；要检查混淆矩阵、主要错误簇和业务代价。

数学按问题恢复：用小数据理解向量、矩阵、导数、概率和统计，再用代码验证。PyTorch 练习要能解释张量、损失、梯度和训练循环，不追求大模型规模。

## 完成信号

- 能说明为什么需要或不需要机器学习。
- 有数据说明、质量检查、规则基线和可重复切分。
- 能解释所选指标、过拟合和数据泄漏风险。
- 完成规则、传统 ML 与 LLM 的对照。
- 模型有推理接口、输入校验和错误分析。
- 能在一份陌生数据上重做关键流程。
