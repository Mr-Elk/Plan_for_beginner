# P4｜学会判断什么时候该用模型

前面几个阶段解决的是“怎样把软件做出来”。这一阶段增加一个新的问题：面对一批数据，究竟该用简单规则、传统机器学习，还是大模型？

你会完成一个小型机器学习应用。题目可以来自公开数据，也可以来自既有产品，例如把用户反馈分成几类、预测某个数值、识别异常记录。关键不是模型多高级，而是整个判断过程经得起追问。

## 从问题和数据开始，不从算法名称开始

先写清楚要预测或判断什么，结果准不准会影响谁。做一个最简单的规则基线，再检查数据来自哪里、有哪些缺失或异常、目标答案是否可靠。

如果数据本身不能支持问题，就应该修改问题，而不是立刻换一个更复杂的模型。

## 数学在用到时回来

处理数据和选择模型时，会重新遇到向量、矩阵、导数、概率和统计。每次只补当前问题需要的部分：能计算、能画图、能解释它怎样影响结果即可。

不需要先把三门大学数学从头学完，也不能完全跳过原理只调用训练函数。

## 做出可以比较的基线

正确划分训练、验证和测试数据，固定随机性，训练一到两个合适的简单模型。根据问题选择准确率、精确率、召回率、F1或回归指标，并解释为什么。

然后检查过拟合和数据泄漏。不要只看一个总分，要找出模型最常犯错的几类样本。

## 体验一次神经网络训练，但保持克制

用PyTorch完成一个足够小的张量和训练循环实验，理解数据、损失、梯度和参数更新怎样连起来。这个实验用于建立模型，不要求追求最强效果，更不需要从零训练大模型。

## 把结果重新放回软件里

为最终选择的模型做一个推理接口，加入输入检查、测试和错误处理。最后对同一问题比较：

- 规则方案是否已经够用；
- 传统机器学习需要多少数据，表现和维护成本如何；
- 大模型能解决什么，又增加了哪些费用和不确定性。

## 完成这一阶段的标志

你应该能拿出数据说明、简单基线、正确的数据划分、指标解释、错误分析和可调用接口。给你一份结构不同的新数据时，你也能重新检查并建立基线，而不是只会复现一份Notebook。
