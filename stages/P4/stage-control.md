# P4 阶段控制表

- 参考窗口：第 25–30 周
- 状态：未来阶段积压
- 目标门：[G4 机器学习闭环门](../../docs/02-capability-matrix.md#g4-机器学习闭环门)

## 控制要点

- 没有数据质量和简单基线，不进入模型调参。
- 数学只补当前决策需要的部分，但必须能用小数据解释。
- 既有 Web 产品只维护，不与 ML 项目形成第二大型主线。
