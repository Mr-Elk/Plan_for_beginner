# P1｜独立做一个 Python 工具

这一阶段要从“代码能跑”走到“能把需求拆成数据、函数、模块和测试”。项目仍是售后工单工具，但它要开始真正保存和查询数据。

## 项目怎样成长

先定义一条工单包含哪些字段，以及新建、查询、更新和关闭工单的规则。用函数完成核心逻辑，再把代码拆成模块。

数据先存 JSON；当查询和更新变麻烦时，再迁移到 SQLite。加入一个小型 AI 功能，例如把聊天内容整理成固定结构。模型返回缺字段或非法值时，程序要能发现并处理。

测试至少覆盖正常创建、重复订单、缺少字段、文件损坏或数据库失败。日志要帮助定位问题，不能只打印“出错了”。

## 同步补的基础

- Python：函数、容器、模块、异常、文件、类型和必要的类。
- 算法：复杂度、数组、哈希、栈队列、树和常见遍历。
- 工程：pytest、调试、依赖、README 和 Linux 运行。

算法练习要回到项目：为什么按订单号查询适合哈希结构，为什么某种搜索会随数据量变慢。

## 完成信号

- 能从空白开始完成一个 90 分钟 Python 小程序。
- 工具能保存、查询和修改工单，主要失败路径有测试。
- 能解释数据结构和模块划分的理由。
- 关闭原答案后，能完成改变业务规则的变式。
- 未参与开发的人能按 README 运行工具。
