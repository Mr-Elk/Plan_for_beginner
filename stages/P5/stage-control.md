# P5 阶段控制表

- 参考窗口：第 31–38 周
- 状态：未来阶段积压
- 目标门：[G5 LLM 原型门](../../docs/02-capability-matrix.md#g5-llm-原型门)
- 交付：一个 RAG 或工具工作流；另一形态只作小型技能任务

## 进入条件

G4 有效；P5 合同已选定唯一主形态，并写清用户价值、数据或工具权限及失败边界。

## 控制要点

- 先完成透明的底层原型，再评估高层框架。
- RAG 与工具工作流只能选一个作为主项目。
- 评测必须区分检索、生成或工具执行失败，不能只看总分。
