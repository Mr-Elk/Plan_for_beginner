# P0 开训检查

本文件只决定能否开始正式训练，不证明 G0 能力。检查顺序固定为：批准总体基线、阶段合同和课程包；完成下表；由验收者给出 S0 结论；通过后才开始第 1 周计时。

## 1. 角色与批准

| 条件 | 当前状态 | 负责人/证据 |
|---|---|---|
| 学习者已读 [P0 指南](README.md)和两份周任务 | 待确认 | 学习者试读结论 |
| 负责人和学习者批准 [阶段合同](stage-contract.md) | 待确认 | 批准人、日期 |
| 负责人和学习者批准 [CP-P0-01](course-packs/CP-P0-01.md) | 待确认 | 批准人、日期 |
| 辅导者、验收者和首次周复盘时间明确 | 待确认 | 角色与日期 |
| 验收者未向辅导 AI 暴露私有材料 | 待确认 | 验收者确认 |

## 2. 环境与仓库

| 条件 | 当前状态 | 通过信号 |
|---|---|---|
| WSL、终端和文件权限可用 | 待验证 | 能创建、进入和删除临时目录 |
| Python、`uv` 和 Git 可用 | 待验证 | 版本可查，最小 Python 文件能运行 |
| 学习项目使用独立 Git 仓库 | 待确认 | 仓库位置和默认分支已记录 |
| `.gitignore` 和密钥示例准备好 | 待验证 | 真实密钥不会进入规划或项目仓库 |
| [证据索引](../../evidence/index.md)可访问 | 已创建，待使用 | 能链接项目提交和复盘，不保存私有答案 |

## 3. 时间、API 与数据

| 条件 | 当前状态 | 通过信号 |
|---|---|---|
| 六天半与 40 小时日程由学习者确认 | 待确认 | 写明每天可用时段和休息边界 |
| 降级方案明确 | 待确认 | 负荷异常时先删 Stretch、Should，不删 Must |
| 模型供应商、模型和官方资料已选 | 待确认 | 只保留一个供应商和一份官方快速入门 |
| API Key、可用额度和费用上限已验证 | 待确认 | 一次受控冒烟调用可执行，费用上限有数值 |
| 只使用虚构数据 | 待确认 | 使用[公开练习样例](materials/public-samples.md) |

ChatGPT Pro 订阅不作为 API 已准备的证据。若使用 OpenAI API，必须按[官方 API 快速入门](https://developers.openai.com/api/docs/quickstart)单独创建并验证 API Key 和可用额度。
