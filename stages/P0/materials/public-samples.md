# P0 公开练习样例

这些样例可以用于开发和公开测试，不属于私有考核。学习者仍需先写自己的输入输出理解，再查看建议行为。

## 1. 普通文本样例

文件 `sample-01.txt`：

```text
订单号：A1001

问题：收到的杯子破损
诉求：补发
```

建议行为：删除多余空行但保留三行有效内容；报告非空行数和另一项自选统计；保存整理结果并显示输出位置。

公开失败样例：文件不存在、文件只包含空白、文件内容无法按约定编码读取。程序应明确失败，不能生成看似成功的空结果。

## 2. 模型假响应

正常响应：

```json
{
  "summary": "用户收到破损杯子，希望补发",
  "category": "商品破损",
  "priority": "normal"
}
```

缺字段响应：

```json
{
  "summary": "用户收到破损杯子",
  "category": "商品破损"
}
```

非法响应：

```text
好的，这是一条需要尽快处理的售后问题。
```

测试目标不是让模型每次生成同一句话，而是验证程序能接受合法结构，并拒绝缺字段或无法解析的结果。自动测试只使用固定假响应，不调用真实 API。
