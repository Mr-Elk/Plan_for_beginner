## 控制要点

- 主交付一次只推进一个 CLI；Git、AI 纪律和时间记录嵌入项目。
- 诊断只决定 P1 从哪里开始，不把 P0 扩成完整 Python 课程。
- CLI 能运行或投入时长不能单独通过 G0。

合同和周任务必须引用任务 ID；G0-01 至 G0-05 均有有效证据后，才能晋级或条件晋级。
