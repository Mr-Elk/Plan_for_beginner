# P0 开训诊断阶段合同

本合同决定 P0 纳入哪些任务、怎样检查 G0，以及什么情况下停止或补修。具体项目需求和每周动作分别见 [CP-P0-01](course-packs/CP-P0-01.md)、[第 1 周](weeks/W01.md)和[第 2 周](weeks/W02.md)。

## 1. 基本信息

- 阶段：P0 开训诊断，第 1–2 训练周
- 规划版本：v0.14
- 控制表：[stage-control.md](stage-control.md)
- 目标门：[G0 训练准备门](../../docs/02-capability-matrix.md#g0-训练准备门)
- 状态：草案，待负责人和学习者批准；批准后执行 [S0](../../docs/14-program-control.md#3-s0-正式开训门)
- 负责人、验收者、批准日期：待确认

批准合同不等于通过 S0。S0 未通过前只能处理启动阻塞，不能开始正式训练计时。当前缺项以 [P0 开训检查](start-checklist.md) 为准，不在本合同重复维护。

## 2. 阶段结果

P0 结束时，学习者应能在 WSL 中运行和调试 Python，用 Git 保存并说明改动，在同一个“售后文本整理器”项目中完成普通 CLI 和最小模型 CLI，并留下真实的 AI 使用、错误和负荷记录。

P0 只建立起步能力和真实基线，不宣称学习者已经达到独立 Python、后端或 AI 工程能力。

| 纵向切片 | 用户动作 | 主要能力 | 独立证据 |
|---|---|---|---|
| 第 1 周：普通 CLI | 把虚构售后文本整理并保存 | Python、文件、错误、测试、Git | A0 基线、可运行项目、失败测试、T1 变式 |
| 第 2 周：模型 CLI | 把整理文本转换为结构化处理草稿 | 环境变量、模型调用、JSON、确定性测试 | 延迟重建、受控调用、A0 变式和讲解 |

明确不做：Web、数据库、前端、RAG、Agent、复杂架构、多供应商比较和 Prompt 优化。只使用虚构数据，不输入真实订单、联系方式、密钥或他人隐私。

## 4. 执行与支架边界

- 主交付流：一次只推进一个 CLI；普通 CLI 未达到退出条件时，不开启模型功能。
- 基础支撑流：终端、Python、Git、文件、错误和测试，只学当前项目需要的最小内容。
- 轻量巩固流：技术英语、AI 记录、延迟重建和复盘，不建立第二门主课。
- AI 边界：教学前基线和 G0 验收使用 A0；练习通常为 A0–A2。A3 只用于非核心 SDK 阻塞，并形成必须重写的学习债务。
- 迁移要求：P0 至少完成 T1 变式；不把 P0 包装成 T2/T3 能力。

单次任务按[高效学习步骤](../../docs/13-efficient-learning-process.md)执行，AI 等级和污染处理以 [AI 使用规则](../../docs/04-ai-use-policy.md)为准。

## 5. G0 验收

| 门条款 | 公开检查 | 必需证据 | AI/资料边界 |
|---|---|---|---|
| G0-01 | 在 WSL 中运行 Python，制造或定位一个常见错误并修复 | 原始终端记录、代码和解释 | A0 |
| G0-02 | 查看 Git 历史，说明关键提交和未提交改动 | 提交记录、README、现场说明 | A0 |
| G0-03 | 演示两个 CLI，完成未见过完整答案的小程序或陌生修改 | 原始代码、测试、变式和评分依据 | A0 |
| G0-04 | 说明 AI 最高等级、密钥边界、污染处理和恢复动作 | AI 记录、配置检查和口头回答 | A0 |
| G0-05 | 审查首周与阶段的真实时间、精力和注意力 | 原始记录和保持、降载或恢复决定 | AI 不得补数 |

私有题目、答案、隐藏测试和评分锚点由验收者隔离保管。验收者不得在检查中实时教学；发生污染时原证据失效，改用等价但不同题面的任务。

## 6. 风险与资源

| 风险或缺项 | 处理方式 | 不得降低的条件 |
|---|---|---|
| 环境无法重复 | 保存复现，由负责人修复 S0 缺陷或提供受控替代环境 | G0-01 仍需独立运行和解释 |
| 模型资料、预算或密钥未确认 | 停止真实调用，只做假响应练习 | 不把假响应冒充真实调用证据 |
| 首次求助直接索要完整代码 | 降到 A1，关闭答案后重写 | AI 使用和未清债务必须如实记录 |
| 40 小时负荷不可持续 | 先删 Stretch、再删 Should，并调整深浅任务 | 睡眠、Must 和 G0 证据优先 |
| 考核材料进入辅导上下文 | 作废受污染证据，更换题面和验收上下文 | 私有材料继续隔离 |

API 供应商、官方资料、预算和真实密钥位置必须在 S0 冻结；本仓库只记录验证结论，不保存密钥或私有答案。
