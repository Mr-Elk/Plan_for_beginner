# P7｜把项目变成求职证据

最后阶段不再开新技术主线。选择最能代表后端与 AI 工程能力的项目，把它整理成招聘者可以检查的证据。

## 收敛旗舰项目

先对照目标岗位，列出项目已经证明的能力和仍影响展示的关键缺口。只修这些缺口，不为了作品数量再做多个 Demo。

确保在线演示、源码、测试和部署说明可用；补齐必要的架构图、数据流、评测、性能、费用、安全和已知问题。让真实用户和外部开发者各完成一次评审—修改闭环。

## 练习提取已有能力

混合练习 Python、SQL、HTTP、测试、调试和代表性算法，不按课程顺序出题。完成一个目标岗位风格的陌生后端任务，并保留原始过程。

准备 30 分钟项目答辩：用户问题、架构、最难故障、AI 失败、安全与成本、关键取舍和后续改进。简历和项目介绍中的每个重要结论都应能指向证据。

## 进入真实市场

选择方向一致的岗位试投递，把反馈分成技术缺口、项目表达、简历筛选和岗位不匹配。每轮只修最明确的一个问题，再复测。

## 完成信号

- 旗舰项目达到章程要求，并有外部反馈。
- 能完成目标岗位的陌生编程和后端任务。
- 能进行 30 分钟答辩并回应追问。
- 简历、README、作品集和演示内容真实一致。
- 有一轮试投递、反馈分类和针对性补强。
