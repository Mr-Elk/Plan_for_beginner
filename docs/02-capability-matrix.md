# 02 能力矩阵与晋级标准

## 1. 能力等级

| 等级 | 含义 | 代表性证据 |
|---|---|---|
| L0 | 尚不能开始 | 无 |
| L1 | 能在示例或提示下完成 | 练习、跟做后的解释 |
| L2 | 能低辅助独立完成常见任务 | 限时任务、陌生变式 |
| L3 | 能处理测试、异常、部署和取舍 | 完整项目、现场修改、答辩 |
| L4 | 能迁移复杂场景并指导他人 | 设计评审、复杂重构、技术输出 |

第一轮训练不要求 L4。目标是 Python、后端和 AI 应用交付达到 L3；算法、数据、机器学习、前端和必要原理达到 L2。

## 3. 通用评分

| 维度 | 分值 |
|---|---:|
| 问题定义与设计 | 10 |
| 功能与完成度 | 20 |
| 无 AI 编程 | 20 |
| 陌生修改 | 15 |
| 原理与口头解释 | 10 |
| 测试、错误处理与质量 | 15 |
| 文档、Git 与部署 | 10 |

- 80 分以上：通过。
- 65–79 分：条件通过，下一课程包携带补修项。
- 64 分以下：未通过，只重做未达标能力。
- 无法解释核心代码，最高只能条件通过。
- 无 AI 任务无法开始，当前核心编程能力不通过。
- 密钥泄露、伪造过程或隐瞒整体代写，本次相关证据无效。

## 4. G0–G7 能力门

### G0 训练准备门

- G0-01：能在 WSL 中创建、运行和调试 Python 文件。
- G0-02：能使用 Git 提交并说明改动。
- G0-03：完成两个小程序和一次无 AI 基线测试。
- G0-04：遵守密钥和 AI 使用规则。
- G0-05：形成首个真实周投入与负荷记录。

### G1 Python 独立编程门

- G1-01：90 分钟内无 AI 完成未见过的小程序。
- G1-02：把需求写成输入、输出、规则和边界。
- G1-03：把程序拆成函数和模块。
- G1-04：正确使用基本容器和异常处理。
- G1-05：为核心逻辑补测试。
- G1-06：完成陌生变式，而不是重复原题。

### G2 后端基础门

- G2-01：把用户流程转成接口、数据模型和验收条件。
- G2-02：从零创建带数据库的 API。
- G2-03：解释请求、业务逻辑和持久化的数据流。
- G2-04：编写常见 SQL，说明索引和事务的作用。
- G2-05：实现认证、输入校验和集成测试。
- G2-06：定位常见 HTTP 与数据库故障。
- G2-07：通过 Issue/PR 响应一次真实评审。

### G3 端到端交付门

- G3-01：说明目标用户、核心问题和非目标。
- G3-02：用户可通过前端完成核心流程。
- G3-03：应用可用 Docker 在 Linux 运行。
- G3-04：具备基本权限、日志和 CI。
- G3-05：处理文件、分页、错误和配置。
- G3-06：现场完成一个前后端修改。
- G3-07：未参与实现者仅凭 README 能运行并反馈问题。

### G4 机器学习闭环门

- G4-01：判断是否需要机器学习，并给出简单基线。
- G4-02：检查数据质量和分布。
- G4-03：正确划分训练、验证和测试数据。
- G4-04：选择并解释合适指标。
- G4-05：识别过拟合或数据泄漏风险。
- G4-06：部署推理接口并完成错误分析。

### G5 LLM 原型门

- G5-01：比较规则、检索、传统 ML 和 LLM。
- G5-02：不依赖复杂框架实现结构化输出或工具调用。
- G5-03：实现文档处理、检索和引用链路。
- G5-04：解释切分、召回和生成的主要失败。
- G5-05：建立最小评测集。
- G5-06：控制输入输出契约和错误处理。

### G6 生产级 AI 门

- G6-01：有离线评测、人工检查和版本对比。
- G6-02：有超时、重试、回退、日志和成本数据。
- G6-03：有提示注入、权限和隐私边界。
- G6-04：工具调用包含参数校验和必要确认。
- G6-05：用前后证据说明优化是否有效。

### G7 综合毕业门

- G7-01：旗舰项目满足章程要求。
- G7-02：有用户反馈和对应迭代。
- G7-03：完成 30 分钟项目答辩。
- G7-04：完成目标岗位的基础编程和后端任务。
- G7-05：解释架构取舍、失败和后续改进。
- G7-06：完成简历、项目介绍和试投递复盘。
- G7-07：完成一次导师以外的人类评审—修改闭环。

## 5. 证据判断

证据强度从高到低：无 AI 陌生任务、现场修改与调试、自动测试与部署、答辩与代码走查、Git 过程、日常练习、观看或证书。低强度证据不能单独晋级。

L2 至少需要 T2 迁移，L3 至少需要 T3 迁移；定义见[质量与证据标准](07-quality-and-evidence.md)。见过完整答案的题只能练习，不能再作独立证据。

面试用于提取和表达已有能力。若失败源于 Python、HTTP、SQL 或 AI 核心知识，应回到对应能力门；若只是表达或时间分配问题，再做专项训练。
