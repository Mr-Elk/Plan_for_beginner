# 理论回顾账本模板

只收录会影响理解、迁移或工程决策的理论。简单语法查询和一次性命令不必全部进入账本。

| ID | 理论/概念 | 触发项目或Bug | 当前状态 | 自己的解释 | 例子 | 反例/边界 | 项目使用点 | 下次验证 | 证据 |
|---|---|---|---|---|---|---|---|---|---|
| T-001 | | | 待理解 | | | | | | |

## 状态规则

- 待理解：无法脱离资料说明概念和用途
- 待应用：能够解释，但没有独立完成相关任务
- 待迁移：在原任务成功，尚未通过陌生变式
- 已掌握：能够解释、应用并通过迁移检查
- 待复测：证据过旧，或新错误推翻了原判断

## 清理规则

- 已掌握且在后续项目自然复现的条目可以归档
- 多个重复条目合并为一个概念，并保留关键错误链接
- 只有摘抄、没有解释和项目使用点的条目不计作完成
- 回顾以主动回忆、变式和项目应用为主，不以重读次数为指标
