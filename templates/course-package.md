# 两周课程包模板

课程包是执行合同，不是第二本教材。解释尽量链接到主资料或独立知识卡，不在多个课程包重复复制。面向学习者的任务、讲解和案例遵守[中文技术内容生成规范](../docs/15-chinese-technical-writing.md)。没有实际用途的模板字段可以标记“不适用”，不能编造内容填满表格。

## 4. 知识块

每个知识块包含：

- 为什么需要
- 前置概念
- 最小示例
- 常见错误
- 一个反例或边界情况
- 口头检查问题
- 在主项目中的应用点

每个新知识块先选择对应的最短学习路径：语法/API、算法、数学/理论、框架/工程或LLM应用。具体学习块按 [高效学习步骤](../docs/13-efficient-learning-process.md) 和 [单次学习块模板](learning-session.md) 执行。
