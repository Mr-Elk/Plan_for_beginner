## 3. 能力合同

| 能力 | 入口等级 | 目标等级 | 状态 | 阶段必需证据 | 对应门条款 |
|---|---:|---:|---|---|---|
| | L0–L4 | L0–L4 | 提前接触/当前主攻/后续加深 | | Gx-条款 |

规则：

- 当前主攻能力必须产生独立证据和迁移证据
- 提前接触只建立最小模型，不能补偿目标门缺口
- 后续加深优先复用已有项目和历史证据，不从头重学
- 每个目标能力至少映射到一个课程包和一个验收证据

## 6. 两周课程包地图

| 课程包ID | 阶段任务ID | 建议窗口 | 唯一纵向切片/阶段活动 | Must结果 | 进入条件 | 退出证据 | 状态 |

| CP-阶段-01 | ST-阶段-xx | | | | | | 草案/批准/完成/替换 |

- 只详细设计当前课程包；课程设计AI最多提前准备下一个课程包。
- 后续行只冻结预期结果和依赖，执行数据出现后才能补充练习、资料和具体任务。
- 课程包变化不自动修改本合同；只有影响阶段结果、门、范围或切片结构时才修订合同。

- 连续失败时只补对应能力，不机械重做整个阶段

## 9. 阶段治理

- 周任务和课程包必须引用阶段任务ID；阶段指南和控制表不能越权宣称合同已批准或任务已完成
- 课程包级调整由周复盘记录，不修改总体版本
- 改变阶段结果、目标门、主项目结构或重要能力深度时，修订本合同并说明影响
- 改变阶段顺序、周数、总体能力门或项目章程时，走总体变更流程
- 每次修订记录触发证据、修改、保持项和回退条件
