# 单次学习块模板

一个学习块只解决一个主要问题。内容简单时可只填写关键字段；需要生成讲解、案例或反馈时，遵守[中文技术内容生成规范](../docs/15-chinese-technical-writing.md)。

- 输入、输出和约束：
- 验收方式：
- 本次明确不学：

- 我的需求重述/伪代码/预测：

- 实际结果：

- 主要缺口：概念 / 设计 / 语法API / 调试 / 前置知识 / 环境范围
- 已经试过：
- 需要的最小输入：

- 主资料及具体范围：
- 获得的关键解释：
